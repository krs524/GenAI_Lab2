fine-tuning and ReVA evaluation experiments. It is not a complete terminal
history or a standalone setup script. Paths refer to my local WSL setup.

4. Qwen Baseline Evaluation
---------------------------
PATH="$HOME/miniforge3/bin:$PATH" \
CONDA_ENV=qwen2 \
MODEL_PATH="$HOME/qwen3-vl-4b-instruct" \
REVA_ROOT="$HOME/reva_dataset" \
REVA_JSON="$PWD/data/reva_test/test_set.json" \
BACKEND=transformers \
MAX_FRAMES=4 \
MAX_PIXELS=50176 \
bash scripts/run_eval_qwen_base.sh

Result: 2574/4000 = 64.35%
Saved summary: outputs/qwen_base/qwen_base/result.csv


5. Qwen LoRA Fine-Tuning
------------------------

CONDA_ENV=qwen2 \
MODEL_PATH="$HOME/qwen3-vl-4b-instruct" \
NPROC_PER_NODE=1 \

GRAD_ACCUM_STEPS=1 \

Result: 200/200 training steps completed.
Local LoRA output: outputs/qwen_reva_sft/
